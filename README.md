# Тестовое задание

## Tunduk - Панель кандидатов

Панель кандидатов для HR-специалиста. В приложении можно открыть список кандидатов, отфильтровать его, найти человека по имени, посмотреть детальную карточку и поменять статус рассмотрения

Проект сделан на моках из задания. По умолчанию используется основной набор данных, а для проверки производительности можно переключиться на большой список

## Что есть в приложении

- список кандидатов с поиском по ФИО, фильтром по вердикту и сортировкой
- пагинация по 10 кандидатов на странице
- сохранение параметров списка в URL
- детальная страница кандидата с контактами, опытом, образованием, стеком, summary и вопросами для интервью
- смена статуса кандидата через mock API
- optimistic update с откатом, если запрос завершился ошибкой
- уведомления об успешном и неуспешном изменении статуса
- тесты на основные сценарии
- виртуализация списка для большого набора данных

## Что важно в реализации

- состояние списка хранится в query params, поэтому фильтры, поиск, сортировка и текущая страница не теряются при перезагрузке и переходах
- данные и мок API вынесены в `src/services`, чтобы UI не был завязан на структуру моков напрямую
- смена статуса реализована в store через оптимистик апдейт, поэтому интерфейс обновляется сразу, но при ошибке состояние возвращается назад
- для большого набора данных включается виртуализированный список, чтобы не рендерить лишние карточки

## Структура проекта

- `src/pages` - страницы списка и карточки кандидата
- `src/components` - компоненты интерфейса
- `src/store` - стор и логика обновления состояния
- `src/services` - моки и мок API
- `src/utils` - утилиты для фильтрации, сортировки и работы с query params
- `src/hooks` - переиспользуемые хуки, включая debounce
